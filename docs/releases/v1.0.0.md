Yewee 1.0.0 is the first release sold through [letissier.ie](https://letissier.ie/yewee). Version numbers restart here, and the old v1.0–v1.4 tags are history.

## Downloads

| Platform | File |
|---|---|
| macOS (Apple Silicon) | `Yewee-1.0.0.dmg` |
| Windows 10/11 x64 | `yewee-setup-1.0.0.exe`. It's unsigned, so SmartScreen warns: choose **More info → Run anyway**. It installs for the current user and needs no admin rights. |

Unlicensed copies run in full for 72 hours. After that, the outputs hold on a TRIAL ENDED slate until a key is entered.

## Licences from the shop

- **Shop keys work.** Paste the `LT-YEWE-…` key from your purchase email into the panel's Licence card. It needs the internet once, to take one of your two seats. After that it runs offline, with a quiet daily check-in.
- **Machines with no internet** can activate offline. The Licence card shows a request code. Enter it at letissier.ie/account under offline activation, then paste back the licence it gives you.
- **Existing `YW1.…` keys** keep working exactly as before.
- **Missed check-ins never stop the output**, and neither does an ended update window. A refunded licence ends at the next launch, never mid-show.
- **Remove licence** frees the seat, so you can move a licence to another machine.

## Safer on a show network

- **The control panel has a PIN.** A four-digit PIN is made on first run and shown in the console and on the panel on the Yewee machine. Phones and other devices need it; the Yewee machine itself doesn't. Five wrong guesses lock that device out for a minute.
- **A frame that fails is skipped**, and the show carries on. After repeated failures the feeds go black, then the detector falls back to YuNet.
- **The installed app restarts itself** if it stalls, and the panel's Restart button now works in the installed app.
- **NDI input that disappears** now cuts to black with NO SIGNAL shown in the panel. Before, the outputs froze on the last frame.

## Also changed

- **Expression labels start switched off.** Turn them on in the panel if you want them; a choice you've already saved is kept.
- **A fresh install starts on the "Mid crowd" preset.**
- **`--no-ndi` now turns off all four NDI feeds.** Before, Faces and Mask stayed on if they had been saved on.
- **The Performance card's cost bars draw again.**
- **The panel fits a phone screen** without scrolling sideways.
- **Crash reports and in-app feedback are opt-in and off by default.** When switched on, they go only to letissier.ie.
- **The installers show LeTissier's terms before installing**, and the dmg carries them as TERMS.txt. Every bundled component's licence ships in the app, including the NDI notice.
- **Licence change:** Yewee's own code is now under the Elastic License 2.0 instead of MIT. Bundled models and components keep their own licences, listed in the app.

## Known limits

- The Windows installer is unsigned until there is a code-signing certificate.
- GPU-accelerated detection on NVIDIA needs the CUDA 12 runtime and cuDNN installed. Without them, Yewee uses the CPU detector (YuNet) automatically.
- The first time an NDI feed is sent, Windows asks about the firewall. Allow Private networks.
